# Конвертер программ ГРП

Инструмент преобразует исходный план закачки ГРП в эталонный Excel-файл «Программа работ».

## Задача

Планы поступают в разных форматах и имеют разное количество строк, столбцов и параметров. Их нужно привести к единому рабочему виду без ручной переделки каждой программы.

## Что делает конвертер

На вход принимает план в формате `xlsx`, `docx` или `pdf`.

На выходе формирует файл `Название (Программа).xlsx` в структуре эталона.

## Основные блоки

- считывание исходных Excel-, Word- и PDF-документов;
- извлечение и сопоставление данных с эталонной программой;
- добавление новых полей и удаление отсутствующих;
- исключение пустых строк, столбцов и нулевых значений;
- сохранение результата в формате Excel;
- локальное веб-окно для запуска и работы с файлом.

## Технологии

- `Python` — основная логика;
- `openpyxl` — работа с Excel;
- `python-docx` — чтение Word-документов;
- `pdfplumber` и `pypdf` — извлечение данных из PDF.

## Запуск

    pip install -r requirements.txt
    python grp_program.py "план.xlsx"
    python app/start.py

После запуска веб-окно доступно по адресу: <http://127.0.0.1:17831/>.

## Проверка

- 17 стадий;
- 10 из 10 прогонов завершились успешно;
